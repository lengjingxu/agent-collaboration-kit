# Security Policy

Do not open public issues for vulnerabilities, credentials, exploit paths, or private data.

Contact the maintainer privately through GitHub, include reproduction steps and affected
files, and allow reasonable time for remediation before public disclosure. Do not submit
secrets, tokens, private endpoints, customer data, or authorization files to this
repository.

This repository contains documentation and low-dependency tooling. Reports about generated
destination repositories should normally go to those destination projects unless the defect
is in this kit's templates or scripts.
